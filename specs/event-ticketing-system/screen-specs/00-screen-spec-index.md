# Screen-Level Product Specs

## Mục Đích

Tài liệu trong thư mục này mô tả hệ thống ở cấp màn hình và hành vi tương tác. Trọng tâm không phải là object có field gì, mà là:

- Người dùng nhìn thấy màn nào.
- Mỗi button làm gì.
- Mỗi input cho nhập gì, validate ra sao.
- Khi loading/error/empty/success thì UI phản hồi thế nào.
- Màn hình kích hoạt hành động nghiệp vụ nào và cần dữ liệu gì.
- QA có thể test theo acceptance criteria nào.

## Design Level

Đây là product/BA spec mức functional UX. Nó chưa thay thế visual design system, nhưng đủ để:

- Designer dựng high-fidelity mockup.
- Developer chia component, API call và state.
- QA viết test case.
- Product owner review flow trước khi triển khai.
